# 首版游戏需求与验收

版本：0.12。日期：2026-10-09。状态：正式游戏设计基线，已完成七区灰盒贯通验证，实际操作空间与数值待真人试玩校准；本次增加通关后有限出口过场与单次宝箱奖励交互。出入口与原创曲谱引导继续为P0。用户确定Python、原创、先规划后实现、三键组合演奏七个笛音及2026-11-03截止；主线使用原创旋律，另有选定参考曲段的隐藏彩蛋需求。本轮建立正式灰盒，实际执行证据见verification.md；独立试听不能替代正式游戏验收。

## 1 产品范围

单人、离线、键盘操作的2D俯视迷宫小游戏；固定原创关卡，约七个相连区域，按剧情分场景呈现。剑台庭与迷宫分开，长斜坡只作为滑落连接过场，不额外画独立场景。首轮体验目标5—10分钟，熟悉后能较快重玩；正常玩家操作时长由实际玩法决定。地图、流程和界面独立设计，默认资源可程序绘制。

## 2 关键状态规则

年龄决定时代；昼夜独立于年龄。切换年龄保留当前昼夜，且只在两时代均有稳定落脚点的剑台发生。勇者进入游戏后没有额外乐器，随身vibe键盘在两个年龄中始终是同一携带物，不是未来场景物传回过去。用户2026-10-08确定货运箱为共享机关：箱子未推开时不能穿过阻挡，仅成年可推；推开后成年与孩童均可双向通行，昼夜均开放。箱子位置与回廊开通状态跨年龄、昼夜保留，参与业务快照/重试，完整重开恢复初始状态。其他时代内状态继续独立，尤其过去鸡群不继承未来位置或仇恨；不将货运箱例外推广为所有机关同步。

玩家昼夜变化只由vibe键盘的正式旋律效果产生，取消独立直切昼夜操作。三键外观保持原版：上方一枚横向语音长键为物理键1、下方左✓为物理键2、右×为物理键3；键帽数量与图标不变。数字1—7代表音符ID，组合键每次发出一个笛子音色的单音，不是和弦，也不改成钢琴音色。

| 数字／音符ID | 三个物理键的组合 | 单个笛音 |
| --- | --- | --- |
| 1 | 键1 | do |
| 2 | 键2 | re |
| 3 | 键3 | mi |
| 4 | 键1＋键2 | fa |
| 5 | 键2＋键3 | sol |
| 6 | 键1＋键3 | la |
| 7 | 键1＋键2＋键3 | si |

独立demo中普通数字对应基础音区，Shift＋数字对应高八度；一条离散音符事件表示为(note_id, octave)，note_id为1—7，octave为0或1。组合高亮多颗物理键仍只形成一条音符事件。正式输入沿用同一音符模型，具体旋律是否使用高八度随原创曲谱定稿，不增加真实麦克风、AI或音高识别。

用户2026-10-09确定：同一首原创时间曲切换昼夜，取消两首分别设昼／设夜方案。灰盒time_shift采用基础八度6-3-2-5-2-1，effect=toggle_day；Enter整段提交，不限节奏，试玩后定最终旋律。第二箱收录egg_lullaby，7-高2-6重复两遍，仅彩蛋反馈，不改世界。鸡回应3-5-3-2为试玩候选。七音、八度和所有完整按法与匹配定义同源；最大前缀12音。

新增隐藏旋律匹配项与原创主线规则区分，复用相同的离散(note_id, octave)输入与校验入口；只支持实际核定且可在支持音区表达的少量短句，不承诺自动识别任意音乐。六首名称已选定；本轮只实现已核验的摇篮曲短句，不改变世界。其余五首准确输入、回应与轻量玩法仍待确定。隐藏项不作为主线解法依赖；核对重复模式、主线/隐藏项前缀歧义和提交时机，单次提交的匹配结果必须明确，不同时误触多个效果。已有试玩合成短句不是正式曲目选择，外部音频与真人声音不参与判定。

InputController持有有界音符事件前缀，max_notes=12由正式校验过的规则决定，不写死为三个。只在达到正式规则定义的完整旋律后提交效果；未完成、合法未匹配或被清空的输入不改世界。非法音符ID、音区、类型、长度/提交格式在边界明确拒绝，合法未匹配给无效果提示。暂停、失焦、失败、重试及重新开始关闭面板并清空未完成前缀，不跨状态补接旧输入。当前试听demo不积累游戏旋律、不触发昼夜或鸡群效果，也不加入《时之笛》曲谱。

移动只能落在完整可站立格。昼夜切换不删除脚下地面；门槛占用期间延迟关门，允许离开门槛，离开后按目标状态关闭。鸡群是接触威胁，不是永久实体路障；安全平台和窄道限制按数据决定，不让鸡堵死重试点。

归巢是可观察的路径信息，不以“看过动画”或拍摄步骤作为胜利硬条件；知道答案的玩家允许直接走正确路线。正式序章由玩家在剑台启动第一次时代切换，随后进入探索，不设置拍摄专用自动状态跳转。

主线胜利需要正式出口位置、少年状态、白天条件及探索阶段同时成立；显示日历是叙事展示，不读取系统日期决定能否通关。首次拔剑后在剑台保存初始探索快照；到达出口前的平台后再更新安全快照。失败重试恢复完整合法业务状态，包括位置、时代、昼夜、门、重物及鸡群状态，不只改玩家坐标；会话事件序号不随快照回滚。

用户新增通关后宝箱及出口过场：跨门胜利后结束本轮追逐，先播放有限的出洞动作与远景展开，过场结束才恢复G内移动与邻近开箱；胜利反馈不能抢先退出场景。过场可跳过，跳过和正常结束落在同一合法状态，均不自动发奖；暂停/失焦冻结进度，恢复不重复触发。宝箱开启/领取为真实产品状态，奖励按固定正式数据展示，不随机抽取；单局只领取一次，重复交互不重复发奖，完整重开恢复未开启及过场初始状态。迷宫通关与奖励领取分开记录，开箱不构成第二次胜利判定；宝箱放置不得堵住出口落脚点。最终结算页在领奖完成后进入或由明确操作进入，具体UI待定。远景是渲染背景，动画不要求增加开放世界、通用攀爬系统或三维运行引擎。

## 2.1 正式玩家引导

出入口引导属于默认产品，不能只存在于演示场景、制作图或作者口头说明。普通通路以场景内路牌或稳定地标提示目的区域；邻近交互提示给出真实可感知的通行条件，随年龄、昼夜和机关状态更新。低矮口说明年龄限制，闭闸说明夜间开放，重物说明成年推动及可施力方向；单行落差在踏入前可见。反馈与真实通行判定同源，不以文字代替规则。

探索通道允许先不揭示终点，用材质、损坏痕迹、脚印或归巢行为引导辨认；不能把制作图中的正确/错误标签、全程解法箭头或区域调试字母直接搬进正式界面。进入区域后显示玩家可理解的区域名称，回到旧区域有明确反馈。

主线乐器提示分清“用途”和“按法”：昼/夜图形配效果文字，每个音符配对应三键组合、音符数字及需要时的八度标记，同按组合明确画成一次单音。打开乐器面板可反复查主线曲谱便签，并查看本次已输入序列、下一步对应图示和错音位置；清空重来有明确操作提示。灰盒实际长度／音符／提交方式已同源实现，最终听感与曲谱仍待试玩定稿，提示不得沿用旧三音候选或从图示槽数预设长度。

曲谱显示由正式匹配定义生成，避免提示一套、实际识别另一套。原创时间曲通过B第一条死胡同宝箱取得，第二条死胡同宝箱提供塞尔达摇篮曲彩蛋谱；完整曲谱展示由已收录ID控制，七音基础按法始终可查，未收录时提示继续探索B。取得后可随时查看且跨年龄／昼夜保留，不另加“必须读过谱才能触发效果”的限制；效果仍只按音符匹配。查谱不代弹、不直接触发效果，也不自动纠正错音。追逐前在安全区提供已取得谱的按法，追逐中仍可看紧凑便签；打开面板继续沿用不自动暂停世界的规则。取得的摇篮曲在独立可选谱便签中展示，不成为主线引导或通关依赖。

时间谱箱与彩蛋谱箱两种年龄及昼夜均可达可开，不能置于依赖其自身曲目的门后。领取原子更新宝箱开启状态和已收录曲谱ID；重复交互不重复领取。两组状态随检查点一起恢复，完整重开重置。F夜间安全入场可刷新检查点，覆盖从B补拿曲谱后再次返回的情况；遗漏时间谱或想补拿可选彩蛋时，可夜间沿F→E→D→B回程。正式验收增加两箱可达、跨年龄保留、重复领取、快照一致、漏拿回程和静音查谱解局；不因视频省略某次开箱而在产品中自动发谱。

## 3 灰盒实际操作

| 输入 | 行为 |
| --- | --- |
| WASD / 方向键 | 移动；边界反馈和按键重复在输入层统一控制 |
| E | 当前邻近对象交互：剑台、指定重物、鸡挑衅、曲谱宝箱、通关后宝箱等按上下文优先级决定 |
| K | 在合法落脚状态打开/关闭乐器面板；关闭时清空未完成前缀 |
| 1—7 | 乐器面板内按上表组合高亮三键并演奏一个七声音符；正式效果等待原创旋律规则完成 |
| Shift＋1—7 | 正式游戏使用octave=1高八度事件，图示与匹配同源 |
| Esc | 乐器面板内关闭面板并清空未提交前缀；地图中暂停／恢复；同一次长按不连续关闭再暂停 |
| R | 失败页恢复完整检查点 |
| F5 | 完整重开，重置曲谱与机关 |
| Enter / Backspace | 乐器中提交完整序列／清空本次输入 |
| Space | 跳过出口远景展开，仍须手动领奖 |

此表为已实现的灰盒键位；独立demo直接试听七音，不包含游戏K面板与世界规则。正式乐器面板聚焦时不把1—7或方向输入转成移动；打开面板不自动暂停世界，失焦或暂停仍统一冻结模拟。按键自动重复不重复收音；失败时关闭面板并清空前缀，避免重试后补出旧旋律。挑衅鸡可以采用挥剑吓唬的喜剧表现，没有伤害系统；它是可选交互，主线不要求虐待动物或逐只攻击。

## 4 功能验收

正式游戏实施后必须实测从默认启动到通关的一整局、一次失败重试和一次重新开始；四个年龄×昼夜组合均可操作并可回剑台。覆盖成年推物后回少年、门槛上演奏原创旋律切换、追逐中演奏切夜、夜间线索后回剑台再前往出口、出口前演奏切白天等关键组合。

通关后实测过场正常结束、跳过、暂停/失焦恢复与完整重开；核对过场期间不触发宝箱、跳过不发奖、恢复不重复过场。再实测G内走近宝箱并打开、两件固定奖励正常显示、重复交互不重复领取、领奖期间不再被本轮鸡群捕获、完整重开重置宝箱；核对胜利反馈没有抢先遮挡或阻断开箱。宝箱与奖品独立于静态地图，默认资源替代也须能完成领取流程。

乐器验收分开记录：独立demo只检查七个音符与物理键组合、单音笛子音色和Shift高八度；正式游戏另检查原创曲谱、音区、完整/未完成/未匹配输入、非法事件、前缀上限、按键重复与生命周期清理。组合键不得被误解为多个音或和弦，未完成正式旋律不能改变世界。效果线索与结果必须有图标/文字反馈；正式游戏静音下实测完整解局。若采用鸡叫P1，相同条件应有可复现回应，不改变既有警戒和主线可解性。实际结果只由正式离散规则产生，不包含真人旋律识别。独立试听不等于正式旋律匹配或完整游戏通过验收。

隐藏彩蛋另测已选完整曲段命中、错音/错八度/未完成输入不命中、主线与隐藏项歧义、重复触发与失败恢复；具体节奏约束定稿后再验证节奏。实际触发应有可见反馈；不知道或完全不使用隐藏曲段时仍能完成原创主线。P1表示接在P0稳定后实现，新增需求不能仅因优先级自动视为已完成或已删除。

用纯模型状态遍历检查主线可达、无非终局封闭状态集合、重试点合法。检查拓扑还需排除鸡群时序与输入行为产生的软锁；路径搜索通过不等于真实操作通过。目标机器上的窗口、文字、按键和声音另行人工验收。

性能先以目标60FPS设计，具体上限、地图尺寸、鸡群数量、响应时间和内存由实际测量后记录，不把设计目标写成已验证支持所有电脑。
