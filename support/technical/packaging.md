# 验证、检查与发行设计

版本：0.8。日期：2026-10-10。正式灰盒包、检查器、源码ZIP和wheel已在本机建立；实际证据见[验收记录](verification.md)，尚未对外发行；另有本机独立七音试听demo。Git在首次实现时初始化，彼时为main分支、无提交、无已跟踪文件。本轮首次技术提交与GitHub推送已授权，仅覆盖审阅后的技术集合，不授权本机内容上传或产品发布；不把试听代码或文档核对写成正式游戏通过。

## 1 统一命令合同

| 实际入口 | 实际应检查什么 | 不能声称什么 |
| --- | --- | --- |
| python -m support.tools.check_project | 工作区语法、规范形式、数据、边界和正式回归 | 不是索引、远程CI或真实GUI通过 |
| 同入口 --staged | 真实索引路径、blob及完整区域资源／拓扑／构建声明；只读解析，不执行索引源码 | 不是工作区测试，也不自动初始化Git |
| 同入口 --check-package | 正式干净快照、源码运行、wheel安装后入口和关键行为 | 不代表原生应用或其他平台通过 |
| python -m support.tools.export_game | 正式允许集合构建，临时校验后替换输出 | 不递归压缩整个工作区 |

工作区/索引检查失败返回非零并指明文件、规则和原因。无索引时说明不适用；构建需要干净检出或用户授权的技术快照，不以工作区混合资料代替。CI未来只检查实际检出版本，复用同一规则；本轮不创建或安装CI/hook。

## 2 正式回归的重点

测试只发现support/tests，不递归到production/scenes；使用受控内存数据与临时目录，不依赖原照、真实账户或本机增强素材。

- 地图状态图：对有限的格位置×年龄×昼夜×机关状态建立抽象状态图，枚举其可达非终局状态，检查存在回安全点/剑台或胜利路径，不只验证一条最短路线。连续插值、计时器和鸡群动态不纳入无界穷举，另用受控时序场景验证。
- 无软锁：门槛切昼夜、成年推物后返回、夜间归巢后切白天、追逐恢复及重试点；地图静态BFS与鸡群动态时序分别验收。
- 机关与状态隔离：未推箱时两龄均不能穿过阻挡，只有成年可推；推开后核对成年/孩童×白天/夜晚四状态均能双向通过货运回廊，切换不重新堵路，retry按快照恢复而restart重置。鸡群等时代状态仍独立，过去鸡不继承未来警戒；不同GameSession之间没有可变容器串扰。
- 生命周期：暂停/失焦不继续移动，重复关闭安全，非法时间增量和数据明确失败，声音不可用时默认静音仍可玩。
- 音符规则：note_id为1—7、octave为0/1，拒绝bool及非法类型/范围；核对三键七种非空组合分别只生成一个音符，不生成和弦。独立demo的Shift＋数字是高八度，不是另一套物理键。
- 正式曲谱：主线只用一首原创时间曲`time_shift`，effect=`toggle_day`，灰盒候选为基础八度6-3-2-5-2-1、Enter提交、无节奏要求。检查完整顺序与八度、前缀上限、模式歧义与效果ID；核对同一旋律能切夜也能切昼，合法未匹配/未完成不改世界，非法长度/类型/提交格式明确拒绝。候选谱可用于灰盒验收，最终听感与试玩定谱另记，不能沿用固定三音或两首昼夜曲旧约定。
- 曲谱取得：B第一只宝箱真实收录原创时间曲，第二只真实收录摇篮曲`egg_lullaby`彩蛋；核对跨年龄昼夜保留、未取得时便签不直接显示完整谱、重试按完整快照恢复、重开重置。第二只宝箱不是通关条件，不通过录像省略或门牌自动发谱。
- 隐藏彩蛋：六首曲名已确定，摇篮曲列为第二只B谱箱内容；摇篮曲7-高2-6重复两遍已经核验，只给可见回应；回归另验正确/错音/错八度/未完成输入、重复触发、与主线规则的歧义及恢复。其余五首具体输入与回应仍待定。主线不使用隐藏项仍能通关，不以试听文件或拍摄demo代替真实触发验收。
- 输入隔离：前缀按正式曲谱规则设有界上限，按键自动重复不重复收音；面板关闭、暂停、失焦、失败、重试/重开都清空；旧前缀不跨状态补接，面板输入不转成移动。
- 乐器结果：从追逐与门槛场景实际演奏切夜/切昼，HUD图标足以理解线索；静音可通关。P1鸡叫在相同条件可复现，不新增追逐或跨时代警戒，不造成随机软锁。
- 正式引导：出口提示与实际年龄、昼夜和机关状态一致；单行落差可预先辨认。曲谱便签由匹配定义同源生成，组合键、八度、长度与实际判定一致，可选谱独立标记，不作为主线必要提示；查谱与清空不触发效果，弹错不自动修正。普通路牌不依赖制作图或作者讲解，探索入口不直接泄露正确/错误标记。
- 新玩家体验：在不看制作图、无作者口头指导且静音的条件下，实际核对能否认出主要出口条件、找到原创主线按法、查谱重弹并完成通关。追逐前能在安全区熟悉操作，追逐中便签不遮住必要危险反馈；该项是后续试玩要求，当前未执行。
- 重试事件：首次拔剑有初始探索检查点，完整业务状态恢复；retry/restart不回滚会话事件序号，声音游标仍能消费后续新事件。
- 完整行为：从默认入口通关、被抓后重试、胜利后重开；基础资源路径与外部显式资源路径分别验证。

只写验证独立结果和实际风险的测试，不复制实现凑覆盖率。注释语义、职责、状态所有权、素材正文与许可仍人工审查。

始终排除：本机混合AGENTS/总入口和Life Plan调度、整个support/production、录屏/配音/配乐、原照/角色参考、创作提示词、来源记录、缓存/虚拟环境及构建产物。忽略规则与检查器采用同一精确允许集合；不整体暂存support。发现历史受限内容时停止推送、报告范围，不自动改写历史。

默认产品必须有完整基础画面、操作提示、七音/音区图标及原创旋律线索，不依赖未获分发许可的媒体。七声音色可程序合成，组合对应单个笛音，不是和弦或钢琴；主线解谜旋律原创，少量选定参考曲段只用于隐藏彩蛋。隐藏规则定义与资源逐项审阅，不因为是彩蛋就自动放行到Git或发行，也不把曲段匹配当成原游戏录音播放。音频不可用时用可读反馈保持主线可玩。增强素材只通过显式参数接入，其本机使用与随包分发分别审阅；必要文字不能只依赖开发机字体。

## 4 干净包验收

先从明确正式允许集合生成临时快照，快照不挂载production目录；声明解释器、构建后端和所有运行依赖。先检验源码入口，再构建wheel，安装到全新虚拟环境或隔离安装目录，运行实际模块入口与console入口。离线复用缓存时如实记录，不声称已验证在线安装源。

清单与七区JSON在.gitignore、project_files精确集合和pyproject package-data分别准确列出；区域结构检查核验一致性，wheel验收直接核对包内实际JSON集合。禁止整体放行areas目录，未知布局与未审阅素材默认排除。

对已安装副本运行受控完整通关、失败重试及重开检查，保证包内地图/规则/原创曲谱/文字齐全；关键操作用正式play_keyboard提交音符事件并按完整旋律触发，不绕过模型直改昼夜。短帧启动只证明基础启动，不能替代关键行为。SDL虚拟显示检查后另验真实窗口、音符/音区输入、文字和声音；不把配音回放描述为真人音频识别。

独立试听目录`support/production/scenes/keyboard_demo/`始终排除正式测试发现、Git与发行；其七音播放或有限帧启动结果不能代替上述正式包验收。试听只检查音符组合、Shift高八度、笛子单音音色与自身生命周期，不要求或声称触发任何原作/正式游戏旋律。

输出集中support/tools/output，构建先校验清单和依赖，在临时位置生成并验证，成功后替换；失败保留旧可用产物。源码ZIP和wheel均需要Python及声明依赖；含解释器的.app/可执行文件是独立工作，本期不默认要求，若新增须单独设计和验收。
